    ↗在 uPic 中使用⌄

    在 uPic 中添加「自定义」图床，按下列内容填写。访问令牌与网页连接时使用的相同。

    请求地址
    /api/upload
    请求方式
    POST
    文件字段名
    file
    Headers
    Authorization: Bearer <访问令牌>
    请求头 Content-Type
    multipart/form-data
    URL 路径
    ["data", "url"]
    域名
    留空

    在「其他字段」中添加上述两个请求头；分享链接可直接打开图片。
